# Beckery

**Beckery** is a playful bakery storefront inspired by Leonhard Brenner's [Kitchensink](https://github.com/leonhardbrenner/kitchensink) Kotlin web-stack project.

This repository currently contains a lightweight static public demo so Beckery can be opened and shared immediately without requiring a database or Kotlin build environment. It borrows the spirit of Kitchensink — a small practical application built from a compact set of useful ideas — rather than claiming to be a drop-in fork of the original codebase.

## Menu

- Blueberry Lemon Layer Cake
- Snickerdoodle Cookie
- Scratch Dumplings
- Becknana Bread
- Beck of the Day

## Demo features

- Responsive storefront
- Product menu
- Working shopping bag stored in `localStorage`
- Demo checkout (no payments are collected)
- GitHub Pages-friendly static files

## Original inspiration

Kitchensink was created by Leonhard Brenner. See the original project and its license at:
https://github.com/leonhardbrenner/kitchensink

Beckery is an independent adaptation/demo and is not presented as an official Kitchensink project.
